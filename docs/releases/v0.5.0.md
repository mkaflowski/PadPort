# PadPort 0.5.0 — Preview

First public preview of PadPort, an Android launcher for your own RPG Maker games.

## Download and install

Download **`PadPort-0.5-debug.apk`** from the assets below and install it on an
**ARM64 Android device running Android 8.0 or newer**.

This is a signed **debug/development build**, version `0.5.0`, build `7`.
It is the same APK installed on the AYN Thor for this preview.

Copy the complete game folder to the device, select **Add game folder**, grant
folder access and press **Play**. No games are included.

- [English instructions](https://github.com/mkaflowski/PadPort/blob/v0.5.0/HOW-TO-RUN.txt)
- [Instrukcja po polsku](https://github.com/mkaflowski/PadPort/blob/v0.5.0/JAK-URUCHOMIC.txt)

## Included

- RPG Maker **MV/MZ** support, with **64-bit GeckoView** as the default engine
  and an optional Android System WebView backend.
- Experimental **XP/VX/VX Ace** support through mkxp-z.
- Physical gamepads, an optional touch controller, editable keyboard mappings
  and a controller tester.
- A game library with artwork, per-game settings and recent-play ordering.
- Save backup export/import. Each MV/MZ browser engine has its own save storage;
  use export/import when switching engines.
- Experimental second-screen panels for **Look Outside** and **To the Moon**.
- English and Polish app UI, following Android's language settings.
- A high-resolution **1024×1024 adaptive launcher icon**, updated library buttons
  and scrollable in-game options.

## Preview status

Compatibility depends on the game and its plugins. RGSS and the game-specific
dual-screen panels are experimental. If a game has problems, include the game
title, device, Android version and diagnostic log in an
[issue](https://github.com/mkaflowski/PadPort/issues/new).

Save normally inside the game. Export save backups before uninstalling PadPort
or clearing its app data.
