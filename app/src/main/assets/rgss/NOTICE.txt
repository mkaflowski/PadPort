PadPort — RPG Maker XP / VX / VX Ace (RGSS) support
=====================================================

Modification of libmkxp-z.so (tools/fetch_rgss_engine.py, PATCHES): the
embedded GLSL sources shader/common.h ("precision mediump float" -> highp) and
shader/tilemap.vert (autotile index clamped to 0..6, default int precision)
are changed in place, byte-length preserving, for correct tile rendering on
16-bit mediump GPUs such as Adreno.

Because GPL code is part of the application, an APK containing this engine is
distributed under GPL-3.0-or-later (Apache-2.0 components are GPL-3.0
compatible) and must be accompanied by the corresponding source code:
the PadPort sources, tools/fetch_rgss_engine.py and the upstream repositories
listed above at the given commit.

No game files, RPG Maker runtime (RTP) or Enterbrain/Gotcha Gotcha Games DLLs
are included. RPG Maker is a trademark of its respective owners; PadPort is
